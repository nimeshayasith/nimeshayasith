## 👨‍💻 About Me

I'm a Computer Engineering graduate from the **University of Ruhuna, Sri Lanka**, focused on **cloud infrastructure, DevOps and Site Reliability Engineering**. I like replacing manual setup with automation that is reliable and repeatable: Terraform for infrastructure, Docker and Kubernetes for workloads, and CI/CD pipelines that verify success instead of assuming it.

I complete two internships (DevOps and Software Engineering) and build projects across **AWS and Azure**. I enjoy tracing a failure to its root cause and fixing it permanently, whether that is Kubernetes networking, IAM permissions or database connectivity.

- 🔭 **Currently:** building cloud and AI-assisted DevOps tools, and finishing my Final Year Project (TETA-Guard)

## 🚀 Projects (newest first)

### 2026

#### ☁️ [CloudFix Buddy: AWS Troubleshooting Agent](https://github.com/nimeshayasith/cloudfix_buddy_agent) · *Individual · Oct 2026*
A guided "one fix at a time" assistant for common AWS problems (EC2 SSH, S3 AccessDenied, IAM permissions, Lambda timeouts, Docker deployment). Amazon Bedrock tool use runs read-only diagnostic checks, so the agent never changes a live account.
`AWS Bedrock` `Lambda` `API Gateway` `CloudFront` `Terraform` `React` `Python`

#### ⚡ [GridPulse: Real-Time Smart Grid Monitoring & Billing](https://github.com/nimeshayasith/smart_grid_energy_monitoring) · *Team of 3 · Sep 2026*
A Kappa-architecture pipeline for live grid-load monitoring, renewable-shortfall alerts and daily household billing, running as 13 Docker services from a single command. **My part:** Docker Compose stack with health checks, Kafka topic design, Airflow DAG, Spark deployment and checkpointing, and the Prometheus + Grafana observability stack.
`Kafka` `Spark Structured Streaming` `Airflow` `PostgreSQL` `FastAPI` `Prometheus` `Grafana` `Docker`

#### 📨 [Kafka Order Processing System](https://github.com/nimeshayasith/Kafka_based_order_processing_system) · *Sep 2026*
A producer/consumer pair exchanging Avro-serialised `Order` messages over Kafka.
`Kafka` `Avro` `Python`

#### 🛡️ [TETA-Guard: Blockchain-Secured Attack Detection for SDVN](https://github.com/nimeshayasith/SDVN-Temporal-Attacks) · *Final Year Project · Team of 4 · Dec 2025 – Present*
A framework to detect and mitigate three topology-poisoning attacks (Topology Time-Warp, Beacon State Heartbeat Hijack, Multipath Echo) in software-defined vehicular networks. **My part:** the Hyperledger Fabric network (trust-weighted PBFT endorsement, OBU ledger replicas, `TemporalEchoMitigator` chaincode), the NS-3 vehicular simulation, and an automated attack-simulation test suite.
`Hyperledger Fabric` `Go / Node.js` `NS-3` `Python` `CouchDB`

#### 🔐 [Post-Quantum Secure Channel for SDVN](https://github.com/nimeshayasith/Information_Security) · *Information Security module · May 2026*
A vehicle-to-roadside secure channel using hybrid post-quantum key exchange (Kyber), HMAC-authenticated beacons, a ±5 s timestamp window and a nonce store. An attack test suite shows replay, duplication and tampering are blocked.
`Python` `Kyber / ML-KEM` `HMAC` `Falcon`

#### 🤖 [AutoTrust Bank: RAG-Based Banking Chatbot](https://github.com/nimeshayasith/ai_chatbot) · *Team · Jun 2026*
BERT (fine-tuned on Banking77) classifies 77 intents, DistilBERT detects distress and routes users to a human before any LLM call, and a FAISS retrieval layer grounds answers from FAQ documents. Llama 3.2 runs locally through Ollama, so no data leaves the machine.
`BERT` `DistilBERT` `FAISS` `LangChain` `Ollama` `Flask`

#### 👁️ [Visual Detection of Deceptive Clickbait UI Elements](https://github.com/nimeshayasith/min_vision_project) · *Computer Vision mini project · 2026*
A computer-vision approach to flag fake download buttons, misleading ads and intrusive pop-ups from webpage screenshots, using transfer learning on CNN/ViT feature extractors.
`Python` `OpenCV` `Deep Learning`

#### 🏨 [SecureStay: Cloud-Native Hotel Booking Microservices](https://github.com/nimeshayasith/SecureStay) · *Team of 4 · Apr 2026*
Microservices (auth, booking, payment, notification, gateway, frontend) with RabbitMQ events, deployed through Docker Compose, Minikube and AWS EKS with a GitHub Actions pipeline.
`Node.js` `PostgreSQL` `RabbitMQ` `Docker` `Kubernetes` `Helm`

#### 🏗️ [SecureStay Infrastructure Pipeline](https://github.com/nimeshayasith/Securestay_infra-pipeline) · *Team of 4 · Apr 2026*
The AWS platform as code: VPC, EKS, RDS, ECR and IAM with S3/DynamoDB remote state, plus a plan-on-PR, apply-on-merge pipeline with a manual production approval gate. Diagnosed an EKS outage caused by VPC CNI IP exhaustion and fixed it by scaling nodes and enabling prefix delegation.
